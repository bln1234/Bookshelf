# Bookshelf 体验改进计划

本轮聚焦本地书架管理、批量导入与朗读体验，继续使用 SwiftUI / UIKit 原生控件和 Readium。

- [x] 书架：列表 / 封面网格、排序、阅读状态筛选、收藏。
- [x] 书籍详情：编辑书名作者、标记读完、查看格式、文件大小和导入时间。
- [x] 批量导入：逐本进度、失败明细，单本失败不终止整批。
- [x] 阅读：睡眠定时、准确的进度持久化、合并频繁写入及后台保存。
- [x] 验证：旧数据解码、筛选排序、导入失败隔离、数据持久化和 iOS 构建。

## 本轮验证（2026-10-31）

- Xcode 27.2，Debug iOS Simulator 构建通过（arm64 / x86_64）。
- 独立 Bookshelf QA 模拟器上的书架回归通过，覆盖旧 JSON、混合导入、状态和进度持久化、合并写入、筛选排序、定时截止与清理。
- 现有全文搜索回归通过：TXT 导入、两个正文匹配、跳转至搜索结果。
- 检查了列表、封面网格、书籍详情与导入结果的模拟器截图。
- 真机长时间锁屏朗读和定时停止效果仍需实际使用验证。

回归入口与手动检查步骤见 `Tests/Library/README.md`。

## 第二轮：书库整理与数据带走

- [x] 自定义书单：创建、重命名、删除；一本书可加入多个书单，和状态 / 搜索组合筛选。
- [x] 标注导出：全部书籍或单本书的划线与笔记，支持 Markdown / UTF-8 纯文本、预览、文件存储与系统分享。
- [x] 可恢复删除：保留进度、书单与笔记；“最近删除”中恢复或二次确认后永久删除。
- [x] 数据保护：旧数组索引自动迁移，损坏索引禁止覆盖，永久删除在提交前后中断均可恢复。
- [x] 验证：旧索引迁移、书单持久化、中文多行导出、删除恢复与故障回滚、搜索回归、页面检查。

入口保持精简：书架左侧菜单集中管理；书籍“…”菜单加入书单；书籍详情与阅读器划线面板提供单本导出。未恢复书签，也不改动翻页 / 朗读引擎。

### 第二轮验证（2026-10-31）

- Debug iOS Simulator 最终构建通过（arm64 / x86_64），`git diff --check` 通过。
- 隔离书架回归全部通过，包括旧索引迁移、多书单持久化、标注按位置排序与多行导出、软删除恢复、提交前后中断恢复、写入失败回滚和损坏索引保护。
- 现有全文搜索回归通过：TXT 两处匹配和 Readium 搜索结果跳转。
- 检查书单管理、加入书单（含多选勾选）、最近删除、导出页面的 iPhone 模拟器截图。
- 全文搜索在书库变动时取消旧任务并移除已删除书籍的旧结果。
- 真机上的系统“文件”存储和系统分享面板仍需手动走一遍；当前已验证导出文本生成，但未声称完成这些系统交互的端到端测试。

后续候选：阅读统计、导入去重与大书库搜索体验。
